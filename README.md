1. 使用增量型PID控制算法
2. 积分、微分增益按照公式转换 Ki = Kp*T/Ti  Kd = Kp*Td/T

（1）测试-参数调整 70%的目标温度整定  使用一半的功率进行温度自整定。  使用的自整定的调试温度为115摄氏度。（如果目标撒热比较快，可能需要降低整定的温度）
 PID_Autotune_Init(&myAT, g_setpoint, 0.24f, 0.24f); 
 对应自整定系数Ku *2
 周期Pu *0.2 
 测试结果： 
 AT_MODE_STANDARD （标准模式下）下到达目标温度后超调2度以内，后逐渐稳定。稳定度较好。------------一个震荡周期后，工作良好  .稳定后波动0.5摄氏度以内
 AT_MODE_MODERATE （适度超调模式）,相比标准模式线下升温较慢，超调在1.2℃以内。-----------达到目标温度后，稳定性较好，工作良好. 稳定后波动0.5摄氏度以内
 AT_MODE_NO_OVERSHOOT（无超调模式下） 重新调整Ki介入的温度（介入的太晚，温度一直上不去）。上升慢，会超调，反应慢。-------------不好使用----->屏蔽，使用适度超调模式下的参数
